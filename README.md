
# Human Activity Recognition Using Machine Learning


## Project Overview
This project focuses on classifying human physical activities using wearable sensor data and machine learning techniques.

The dataset contains time-series measurements collected from wearable sensors. The objective is to identify 12 different physical activities based on sensor signals.

## Dataset Overview
- Training samples: 679
- Testing samples: 403
- Sensor channels: 23
- Time steps per sample: 250
- Original features: 5,750
- Activity classes: 12

## Project Workflow
1. Data Loading and Exploration
2. Exploratory Data Analysis (EDA)
3. Data Cleaning and Preprocessing
4. Missing Value Investigation and Handling
5. Time-Series Reshaping
6. Statistical Feature Extraction
7. Machine Learning Model Training and Evaluation
8. Activity Prediction

## Feature Engineering
Extracted 14 statistical and signal-based metrics from each of the 23 sensor channels, resulting in 322 features per sample.
